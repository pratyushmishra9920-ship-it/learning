## Project Details
**Project Name:** Student Score Predictor

## Description
A machine learning project that predicts a student's exam score based on study hours.

## Features
- Predicts student marks
- Trained using Linear Regression
- Easy to use
- Beginner-friendly

## Tech Stack

| Library | Purpose |
|---------|---------|
| Python | Core programming language used to build the application. |
| Pandas | Load, clean, manipulate, and analyze data. |
| NumPy | Perform numerical computations and work with arrays. |
| Scikit-learn | Train and evaluate machine learning models. |
| Matplotlib | Create data visualizations and plots. |

## Installation
1. Clone the repository.
2. Install the dependencies.
3. Run the Python file.

## Usage 
Predict the score by providing the number of study hours.

### Example 
Input:
```
Study Hours = 8
```
Output:
```
Predicted Score = 86.5
```
